## 📌 Example: Creating a Node (Preview)
```c
struct Node {
    int data;
    struct Node* next;
};

struct Node* head = NULL;

int main() {
    struct Node* newNode = malloc(sizeof(struct Node));
    newNode->data = 5;
    newNode->next = NULL;

    head = newNode;

    printf("Head → %d\n", head->data);
}
```
